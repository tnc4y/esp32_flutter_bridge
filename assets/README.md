# Assets

Place your 10-second demo animation or screen recording here:
- `demo.gif` (Recommended width: ~650px)

### How to create an effective demo GIF:
1. Run the Flutter app and power on your ESP32.
2. Tap "ESP32 Wi-Fi Ayarla" to open the bottom sheet.
3. Select an SSID, type the password, and press Connect.
4. Show the ESP32 connection status turning to "connected" and reporting its local IP.
5. Toggle the LED switch to show bi-directional JSON communication.
6. Convert the screen recording using tools like `ffmpeg`, Gifski, or CleanShot X.
